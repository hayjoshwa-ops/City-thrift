# Super 1 Foods

Marketing website for Super 1 Foods — family-owned community grocery stores across Idaho, Montana, and Washington.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Online shopping links to the Super 1 Foods NW Instacart storefront at [shop.super1foods.net](https://shop.super1foods.net/store/super-1-foods-3516964643788363061/storefront).
